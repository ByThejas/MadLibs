# 🎮 MadLibs — my first Java project fr fr

started learning Java literally TODAY and this is what i built by following a tutorial 💀 no cap

it's a Mad Libs game — you drop in some random words (adjective, noun, verb, whatever it asks) and Java stitches it into a chaotic little story for you. that's it, that's the whole thing. but it WORKS and i wrote it and i am extremely normal about that.

## what's actually in here

- `src/Main.java` — the OG console version. plain, simple, does the job.
- `webapp/` — glow-up edition. same madlibs energy but now it's a full browser game:
  - asks for your username first (main character intro moment)
  - dashboard where you pick a vibe: F1 🏎️, Harry Potter ⚡, or Marvel 🛡️
  - background actually changes based on the theme you pick
  - random story template every time so it doesn't get boring
  - deployed on Vercel because why not, we go big or go home

## why this exists

no reason. just vibes. started coding today, wanted to make something that felt like *mine* instead of just copy-pasting a tutorial line by line. this is proof i can go from zero to "yes i shipped something" in one sitting.

more stuff coming as i learn more Java (and probably break things along the way, that's the process).

## running it

**console version:**
```
javac src/Main.java -d out
java -cp out Main
```

**web version:** just open `webapp/index.html`, or check the live Vercel link.
